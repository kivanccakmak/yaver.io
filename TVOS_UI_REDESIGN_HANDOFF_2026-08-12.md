# tvOS Dashboard Redesign + Relay Self-Heal — Handoff (2026-08-12)

Status: **coded + compiles (tvOS Debug + visionOS Debug, `CODE_SIGNING_ALLOWED=NO`)**.
Not run on a simulator/device — verification is on the user's other PC / TV per request.

## What changed

The tvOS dashboard was 12 tiles. It is now the **webui's five surfaces** plus a
profile menu, a clearly-labelled connected-PC card, an auto-repairing relay
credential path, and dictation-first vibe input.

### 1. DashboardView.swift — 5 surfaces, not 12

- **Devices** → `MachinePickerView` (your account's machines, liveness, wake)
- **Chat** → `TasksView` (retitled from "Tasks" — web/mobile chat parity)
- **Projects** → `ProjectsView`
- **Vibing** → `SessionView` (drive a live coding session)
- **More** → sheet with the secondary tools that used to be their own boxes:
  Runtime, Apple TV remote, Capture, Android (redroid), Feedback

- **Profile menu top-right** (person icon): Sign out (destructive) + Update agent
  + Shared with. Sign-out is no longer a tile.
- **Connected-PC card** is now the first thing the initial screen shows: machine
  name + status chip (green Connected / orange Unreachable / gray Checking,
  driven by `BoxLifecycle.reachable`) + host + relay-fallback + runner/render
  split badge + Switch. Auto-connect narration ("Connecting to X…" with a
  "choose myself" bail) unchanged.

### 2. Relay self-heal — the "invalid relay password" fix

tvOS previously surfaced the relay's `invalid relay password` as a dead error.
Now every client (AgentClient + SessionClient) carries a `relayRepair` closure
injected by `YaverStore`:

1. A relay-leg failure matching `FailureSignals.isRelayCredentialDeny` triggers
   `POST /settings/repair-relay` (same endpoint mobile/web use) **once per
   streak** — never a loop.
2. `/settings` is re-fetched, the corrected password is adopted onto the
   selected box (`YaverStore.repairRelay() -> BoxTarget?`), endpoints are
   recomputed, and the request is re-run once.
3. If repair fails, the error is thrown with `AgentError.relayDeny = true` so a
   view can render a named repair route instead of "Try again".

SSE streams (task output, dev events) now name relay 401/429 verdicts instead of
a bare "HTTP 401".

### 3. Siri Remote mic → dictation-first vibe

tvOS has no mic API; the Siri Remote mic button dictates into a **focused**
text field (system dictation, `docs/yaver-tvos-surface.md §1.1`). So:

- `TaskComposerView` ("New vibe") auto-focuses the prompt on appear — one press
  of the mic button starts dictating. Deep-audit (`askMode`) chip unchanged.
- `VibeTurnPanel` focuses the prompt the moment it expands and shows a hint.
- `TasksView` (Chat) header shows the hint: dictate on the TV, or start with
  whisper on the iPhone — phone-started tasks land in this same list.
